# mimiスペシャル(マニュアルコントロール)

## 詳細

mimiのアームとか音声などのサービス、トピック類を動かすのが面倒くさいと思うときありませんか  
例： `ros2 topic pub ~~~~~`  
上記の長ったらしいコマンドを打つには覚えればいけないことがあったりするよね。  
このパッケージはそれを解決すべく誕生したありがたき存在‥  
トピックやサービスをGUIで直感的に動かしましょう  
誰も止めることはできません…  

## 実行方法

実行方法をこんな感じである  
```bash
ros2 launch gui_pkg mimi_special.launch.py
```
